# STL to Spherical Harmonics Expansion

Короткий исследовательский pet-проект для математического моделирования и анализа 3D-объектов. Скрипт считывает геометрию из `.stl` файла, переводит её в сферическую систему координат и выполняет разложение формы поверхности по сферическим гармоникам с последующим восстановлением.

Сферические гармоники — функции $Y: [0, \pi] \times [0, 2\pi] \to \mathbb{C}$ вида $Y_{\ell}^{m}(\theta, \phi) = \sqrt{\frac{2\ell + 1}{4\pi} \frac{(\ell - m)!}{(\ell + m)!}} P_{\ell}^{m}(\cos \theta) e^{im\phi}$
образуют ортогональный базис в гильбертовом пространстве $L^2(S)$.

## 💻 Стек технологий

* **Python** — основной язык разработки
* **Jupyter Notebook** — среда для прототипирования и исследований
* **NumPy** — матричные вычисления, численное интегрирование, работа с массивами
* **PyVista** — рендеринг и 3D-визуализация полигональных сеток

## Что реализовано (математика и алгоритмы)
1. Парсинг полигональной сетки (mesh) из STL-файла.
2. Трансформация декартовых координат $(x, y, z)$ в сферические $(r, \theta, \phi)$.
3. Вычисление коэффициентов разложения (интегрирование формы по базису сферических функций).
4. Динамическая 3D-визуализация с использованием `pyvista` для наглядной оценки сходимости ряда к исходной форме объекта.
